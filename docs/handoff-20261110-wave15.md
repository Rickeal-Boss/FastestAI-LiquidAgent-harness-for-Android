## 一、本波定位与裁决收敛

W15 = **功能矩阵波（同组交叉格）+ 外审分歧裁决落账订正波**。不是重做内核、不是安全收口、
不是拆分重构，也**不是**外审排期里的「先还债再开新面」。

**收敛结论（唯一目标以此为准，完整版见 `docs/analysis/w15-matrix-acceptance.md` §1.2）**：

1. **顺序沿用 W14 的「用户指令面优先」**：主干照用户唯一目标跑真机矩阵 + 推 CI；外审排期
   **不取消、不推翻、不写已核销**，整包挂账顺延。
2. **对已命中的触发信号只做最低限度纯文档缓解**：`W14-01`（外部审查再次判账实不符）、
   `W14-04`（下一波仍以功能矩阵优先）、`W14-11`（功能项重新验收）三条触发信号本波**均已命中**
   ⇒ 本波执行的缓解 = **五处数字订正 + 五处分歧裁决留痕 + W15 派生件自带五列**，属
   **部分缓解、未核销**；逐条落号仍由 `W15-01` 顺延。
3. **四项用户裁决不代做**：`W9-05` 开波 / 「≥3 端点」二选一 / 占位符口径 / `P2-3` 二选一。
   本波**执行**补跑同组交叉格属「执行」不是「裁决」。
4. **五处事实分歧的收敛结论**：
   - 严格 `@Test` 真值 **799**（800 是宽松 grep 把 KDoc 计入的离群值；`796` / `8 条` 是台账
     `W9-04` 行的失实孤例，本波已订正）。
   - G20 实跑 **74 个 handoff ID**（63 / 73 均为文档磨损值，守卫未错）⇒ 文档**一律不写死 G20 数字**。
   - 「≥3 免费端点」上一波是 **⚠️ 部分达标**（批量收敛端点仅 2 个、第 3 个来自非同组功能格）；
     **同组交叉格判据此前从未被行使 ⇒ ⛔vacuous**。本波要补的正是这一格。
   - `W9-05` 的 7 / 8 / 9 是 W11 / W12 / W14 三个波次快照混写进同一真值源 ⇒ 本波第 **10** 次顺延

     §一 老行不改（改老行需单独裁决）。
