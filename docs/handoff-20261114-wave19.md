W19 = **补铺矩阵波**：在零 `.kt` 改动的前提下，用用户本单新给的多支可用免费节点，
把 W18 判 ⛔ / ⛔vacuous 的「多免费节点模型 × 多档位上下文（直至 1M 读数）× 全功能面」

**收敛结论（唯一目标以此为准，完整版见验收物 §1.2–§1.4）**：

1. **用户指令面优先**（沿用 W14/W15/W16/W17/W18 五波同款裁决，出处 `w17-acceptance.md:98`）：
   外审还债排期不取消、不推翻、整包顺延；「不改方案大体方向」= 不把本波转向外审推荐的第 0 车。

   免费节点**，正面回应 W18 的端点池环境障碍，故本波按原「≥3 端点」口径组织矩阵，
   但**不代改该裁决的终局口径**（只留痕，见验收物 §1.4 分歧 5）。
