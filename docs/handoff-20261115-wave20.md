## 一、本波定位与裁决收敛

W20 = **补铺矩阵波**：在零 `.kt` 改动的前提下，用用户本单新给的多支可用免费节点，
把 W19 判 ⛔ / ⛔vacuous 的「多免费节点模型 × 多档位上下文（直至 1M 读数）× 全功能面」
在真机逐格补铺并四态如实取证。不是裁决波、不是拆分波、不是安全波、不是账实收口波、
不是 journal 波、不是基础设施波。

**收敛结论（唯一目标以此为准，完整版见验收物 §1.2–§1.4）**：

1. **用户指令面优先**（沿用 W14/W15/W16/W17/W18/W19 六波同款裁决，出处 `w17-acceptance.md:98`）：
   外审还债排期不取消、不推翻、整包顺延；「不改方案大体方向」= 不把本波转向外审推荐的第 0 车
   （决策包 / 账实收口 / 停矩阵 / 四问选择器 / 拆分先行）。
2. **矩阵欠账是本波唯一目标**：三份外审在排期上一致主张「停矩阵 / 转拆分 / 递决策包」，
   而用户本单第六次给出同款矩阵指令并**再次新给可用免费节点**正面回应 W19 的端点池环境障碍
   ⇒ 排期主张整包顺延，本波按原「≥3 端点」口径组织矩阵，但**不代改该裁决的终局口径**（只留痕）。
   同时**采纳外审的成因诊断作为判据前置**：端点连通性 fast-fail 预筛、长对话夹具、严格 `ls -1`
   落盘与 ≥200×120 真图先备好再铺格。
3. **零 `.kt` 改动**：审查席逐模块实跑三模块余量 4 / 5 / 4 行、`ChatViewModel` 500/500，
   任何 `.kt` 增量必撞 G10。拆分是独立波（老号原样 `OPEN`），塞进测试波会改变单波归因
   ⇒ 裁决为「不做拆分、也不改 `.kt`」。
4. **众审查人分歧逐条裁决**（验收物 §1.4 十二条）：含设备 / 模型可行性的关键证伪 ——
   `AGENTS.md` §一明确本仓从 LiquidAgent 分叉后**端侧推理核心全部移除**，模型全在云端 ⇒
   本波「多模型」只指设备侧 `endpoints.json` 的远程端点，知识库端侧引擎判据**全部不适用**，
   不照搬为候选模型筛选依据。方案席如实标注共享知识库本机不存在、改读等价件并标注未读。
5. **三处证据分级订正（本波不把推断写成事实）**：① 外审报告② P0-1「三态打架」经审查席

   变动」处方经逐 commit 实算与守卫实现核对**证否**，两方案皆不可做，只在验收物 §2.1 写显式

   重试 ⇒ 只能写「静态未定位、待真机取证」，不写成应用行为事实，挂本波段第 18 行。
6. **四项用户裁决不代做**：journal 二选一第 15 次顺延（本波段第 1 行登记，两代数口径并列）、
   「≥3 端点」终局、§1.5 占位符口径、`P2-3` 二选一；只留痕，不软化、不关号。
