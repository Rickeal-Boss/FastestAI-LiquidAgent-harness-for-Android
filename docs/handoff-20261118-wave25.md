## 一、本波定位与裁决收敛

W25 = **「两份审查报告分歧裁决 + 新节点×多上下文×多功能面真机矩阵 + 上一波收尾契约次级收口 + 挂账账实补行」复合波**：

**收敛结论（唯一目标以此为准，完整版见验收物 §1.1–§1.5）**：

1. **用户指令面优先**：两报告的排期主张（转代码波 / 先拆三方 / 新波段三行结构借鉴落笔）整包顺延留痕、不取消不推翻；
   矩阵存续决策包维持台账原样 `OPEN`。用户本单仍给 API 与新节点、明确要矩阵测试 ⇒ 指令面优先。

   在上一波段末补一行 journal 第 19 次顺延（状态 `OPEN`、触发信号/缓解动作/证据齐），消除验收物两处引用、
   交接声称已登记、台账零行的账实不符；**不代裁** journal 二选一本身，第 20 次顺延本波不新开行、留痕待后续。
3. **结构借鉴草案整包顺延**：上一波挂账草案的 11 单元对账「外部仓事实」按用户材料采信，「本仓映射」按深度审查订正后才用；

   判据密度口径（不按 LOC 折算）采纳、不据此转代码波。
4. **收尾契约缺陷修复并入本波**（零 `.kt`）：补上一波推送 2 自身 run 链接（公开 API 复核后回填）；
   「同上一波」抹平实质增量的措辞订正（上一波 F6 自动压缩为 ✅ `dropped=19`、本波未复现为 ⛔vacuous，不改写历史）；
