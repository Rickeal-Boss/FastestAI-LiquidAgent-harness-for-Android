## 操作链（✅ 通过）
1. 设置→端点管理→端点 B 卡片→「编辑端点」页。
2. 点「高级配置」→ 由「展开」变「收起」，逐字出现分组：能力 / 工具调用 / 图片输入 /
   JSON 模式 / 思考 / 输入 / 输出 / 自定义协议。
3. 自定义协议下「启用自定义协议」初始为 OFF（截图：轨道浅灰、滑块在左），无键值输入行。
4. 打开「启用自定义协议」→ 逐字出现提示行：每行一条 键=值（保留键不可覆盖）
   → 输入框出现（bounds [78,1719][1002,1863]）。
5. 在输入框写入 ASCII：parallel_tool_calls=false → dump 逐字行：
     parallel_tool_calls=false  @(78,1588)-(1002,1732)
6. 点「保存」→ 页面退栈回「端点管理」，保存链未拒绝、未报错、未留在编辑页。
7. 重开同一编辑页→展开高级配置→滚到底，dump 逐字行仍在：
     parallel_tool_calls=false  @(78,1588)-(1002,1732)
   ⇒ 键值持久化保留（非仅草稿态）。
